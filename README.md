# PathFinder-OS-
Project Title

Pathfinder OS | Multi-Path Simulation

Project Idea / Overview

Pathfinder OS is an interactive career simulation web app that models multiple potential career trajectories based on user input skills and industry. It uses branching logic and reality modeling to provide a dynamic, immersive experience with a futuristic design. Users can input their core skills and target industry, then explore various career paths, each with an interactive roadmap and live simulation stats.

Key Features of the Project

Multi-path career simulation: Users choose between different career trajectories (e.g., Executive Leadership, Technical Mastery, Freelance Consultant).

Interactive roadmap: Each path has a 10-year timeline with expandable detailed steps.

Live HUD stats: Real-time simulated stats like Economic Stability and Skill Relevance, visualized with animated progress bars.

Reality checks: Randomized risk messages highlight possible challenges or setbacks in the chosen path.

3D animated background: Uses Three.js to create a subtle 3D torus knot animation as a futuristic visual effect.

Smooth transitions: Page navigation and element animations powered by GSAP for fluid user experience.

Responsive, modern UI: Styled with Bootstrap 5 and custom CSS variables for a sleek dark theme with glassmorphism effects.

Tech Stack Used

Frontend:

HTML5 & CSS3 (with CSS Grid and custom properties)

Bootstrap 5.3.3 for responsive layout and styling

JavaScript (ES6+) for simulation logic and interactivity

GSAP (GreenSock Animation Platform) for animations and transitions

Three.js for 3D graphics rendering in the background

Google Fonts (Syncopate & Space Grotesk) for typography

No backend included in this version (pure frontend simulation)

Steps to Run the Project

Download or copy the HTML file with the code you provided.

Open the file in any modern web browser (Chrome, Firefox, Edge).

You will see the landing page ("PATHFINDER.OS") with a Start Simulation button.

Click Start Simulation, input your core skills and target industry, then click Initialize Multi-Path.

Explore multiple career paths, view interactive roadmaps, and watch the live simulation HUD update dynamically.

Use the Reset System button to start over anytime.
